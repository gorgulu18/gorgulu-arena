# GÖRGÜLÜ ARENA

Aile içinde günlük oylamalar, rozetler, sonuç sahnesi ve bugüne bırakılan cümleler için kurulabilir PWA.

## Ücretsiz yayın

Bu klasör doğrudan Vercel veya Netlify gibi statik site servislerine yüklenebilir.

Telefon kurulumu:

1. Yayın linkini iPhone'da Safari ile aç.
2. Paylaş simgesine bas.
3. `Ana Ekrana Ekle` seç.
4. Uygulama ana ekranda `GÖRGÜLÜ ARENA` adıyla görünür.

## Sonraki aşama

Firebase ile aile kodlu ortak bulut sistemi eklenecek.
